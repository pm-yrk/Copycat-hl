# Token icon sources

Copycat uses local token icon files only.

## Primary source

Some local token icons are from `spothq/cryptocurrency-icons`, licensed CC0-1.0:
https://github.com/spothq/cryptocurrency-icons

The original project states that it contains thousands of cryptocurrency icons
across multiple styles/sizes and includes SVG versions.

## Fallbacks

If a Hyperliquid token does not exist in the open icon set, Copycat uses a
locally generated ticker badge. These fallback badges are Copycat-owned SVGs.

## Rules

- Do not hotlink token logos from CryptoLogos, TradingView, CoinGecko, CoinCap,
  TrustWallet GitHub, jsDelivr, or other public CDNs.
- Store reviewed icons locally.
- Keep this notice with the repo.
- Token names/logos may be trademarks of their respective owners. Copycat is not
  affiliated with or endorsed by any token issuer.
